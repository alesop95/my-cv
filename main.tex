% Infrastruttura multilingua (Fase 5 di .claude/context/roadmap.md, avviata il 2026-07-06,
% estesa a tre lingue lo stesso giorno su richiesta esplicita). Principio: altaCV resta solo
% motore di rendering, il contenuto diventa un dato parametrico e la lingua un parametro di
% compilazione, invece di duplicare main.tex. \CVlanguage vale "en" (default), "it" o "es";
% \cvtext{italiano}{spagnolo}{inglese} restituisce la versione attiva. Per compilare in
% italiano: \renewcommand{\CVlanguage}{it}; in spagnolo: \renewcommand{\CVlanguage}{es}.
% Il contenuto italiano e spagnolo NON è ancora stato scritto in nessun punto del documento:
% va fatto sezione per sezione, con l'utente che scrive il testo o rivede una bozza proposta,
% non inventato qui (vale soprattutto per lo spagnolo, lingua di studio in corso dell'utente:
% da valutare se pubblicare una versione spagnola senza revisione madrelingua).
% \providecommand (non \newcommand): permette a scripts/build-multilang.ps1/.sh di iniettare
% \providecommand\CVlanguage{it} sulla riga di comando di pdflatex PRIMA di \input{main.tex}.
% \providecommand definisce solo se il comando non esiste già, quindi l'iniezione esterna vince
% senza errori "già definito"; se non c'è iniezione (build normale), vale il default "en" qui.
\providecommand{\CVlanguage}{en}
% \cvtext usa un confronto \ifx di TeX puro, non \ifdefstring di etoolbox (usato nella prima
% versione del 2026-07-06): \ifdefstring non è "edef-safe", quindi si rompe silenziosamente
% dentro \MakeUppercase (usato da \cvsection sui titoli di sezione), cadendo sempre sul terzo
% argomento (inglese) anche a \CVlanguage impostato su "it" o "es" - bug scoperto e verificato
% con un test isolato durante la prima traduzione completa (2026-07-07). \ifx confronta le
% macro per definizione, non per nome: \CVlangIT e \CVlangES hanno la stessa definizione "it"/
% "es" di \CVlanguage quando quest'ultimo vale quella lingua, quindi il confronto è vero anche
% dentro \MakeUppercase, \edef e qualunque altro contesto di espansione forzata.
\def\CVlangIT{it}
\def\CVlangES{es}
\newcommand{\cvtext}[3]{%
  \ifx\CVlanguage\CVlangIT #1\else
  \ifx\CVlanguage\CVlangES #2\else
  #3\fi\fi
}
